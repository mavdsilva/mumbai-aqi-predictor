# Mumbai Hyperlocal AQI Monitoring System

A dual-stack approach to environmental monitoring in Mumbai.

### Technical Stack:
- **Backend:** Node.js, Express (REST API)
- **Frontend:** React.js
- **Data Analysis:** Python, Pandas (Pollutant Correlation)

### Research Focus:
This project analyzes the correlation between Mumbai's hyperlocal coordinates and pollutant density (PM2.5, NO2). Using Time-Series data from OpenWeather, it visualizes air quality trends to help citizens identify pollution hotspots.
